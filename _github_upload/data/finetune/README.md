# 微调数据集说明

由 `scripts/clean_data.py` 从原始语料 TSV 生成（**数据文件未随仓库提供**）。

## 文件

| 文件 | 说明 |
|---|---|
| `sft_train.jsonl` | 训练集 |
| `sft_val.jsonl` | 验证集，**按标题切分，与训练集无标题重叠** |

## 样本格式

```json
{"instruction": "你是一名资深电商文案策划。请根据商品标题, 撰写一段有感染力的商品推广文案。",
 "input": "商品标题",
 "output": "描述文案",
 "meta": {"cat": "类目", "style": "风格(自动标注)", "len": 88}}
```

`meta.style` 是用关键词启发式自动标注的（`促销带货` / `种草安利` / `品质参数` / `场景叙事` / `常规描述`），
精度有限，用于抽样分析可以，**不建议**直接当训练标签做多风格条件生成。

## 清洗策略（`scripts/clean_data.py`）

从原始语料中剔除了以下几类样本：

| 原因 | 说明 |
|---|---|
| 标题重复对 | 归一化后 `(标题, 文案)` 完全相同的只留一条 |
| 超过「每标题条数上限」 | 个别标题有数百条变体，截断以保证检索结果多样性 |
| 文案长度越界 | 过短/过长都不适合作为卖点文参照 |
| 文案质量不合格 | 违规词、乱码、重复字符、非中文占比过高 |
| 标题长度越界 | 过短标题召回噪声大 |

保留比例大致在原始行数的一半左右（截断一项占比最大）。

## 类目分布

语料以**服饰鞋包类**为主，其次为家居日用与母婴玩具；具体各类目数量随数据源不同而变化，
详见 `data/index/cat_dist.json`（随本仓库提供，是真实运行产物）。

## 文案长度分布

集中在 **60–120 字**区间，与「电商卖点短文」的定位一致（详见 `data/index/index_meta.json` 的 `avgdl`）。

## 建议

- 全量样本对 LoRA 来说偏多，建议先用 `finetune_lora.py --max-samples 200000` 跑一轮看效果。
- 语料以服饰鞋包为主，做其他类目时建议按 `meta.cat` 采样平衡，或补充垂类数据。
- 文案均长 88 字，`--max-length 512` 足够，不需要长上下文。
